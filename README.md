# Jan Isaac — Software Engineer & Systems Showcase Portfolio

> Live Deployment: [https://is-project-2026.github.io/portfolio-138141/](https://is-project-2026.github.io/portfolio-138141/)  
> Organization: **IS-PROJECT-2026** &bull; Class Team: **GROUP 4A**

An interactive, AI-enhanced, and performance-optimized Developer Portfolio engineered by **Jan Isaac** for the Strathmore University IS Project engineering curriculum.

---

## 🌟 Key Interactive Features

1. **Dynamic Project Catalog & Deep-Dive Modal**:
   - Filter systems across *Web Applications*, *Systems & Tools*, and *Mobile & IoT*.
   - Architectural case study popups explaining challenges, solution strategies, and tech stacks.

2. **Interactive Developer CLI Terminal (`Ctrl+K`)**:
   - Built-in interactive command-line interface.
   - Run commands such as `help`, `whoami`, `projects`, `skills`, `contact`, `git`, and `clear`.

3. **Technical Skill Proficiency Matrix**:
   - Visualized competency across Frontend, Backend & Systems, and DevOps / Workflow tools.

4. **Client-Side Validated Contact Engine**:
   - Regex-based email and message validation with animated Toast feedback and `LocalStorage` persistence.

5. **Theme Switching Engine**:
   - Seamless toggling between Dark Mode and Light Mode with persistent browser state.

---

## 🛠️ Technology Stack

- **Core Structure:** Semantic HTML5, ARIA accessibility attributes.
- **Styling Architecture:** Vanilla CSS3, CSS Custom Properties (Tokens), CSS Grid & Flexbox, Backdrop Blur Filters.
- **Application Logic:** Vanilla JavaScript (ES6+), DOM API, Browser LocalStorage API, Event Delegation.
- **Typography & Icons:** Google Fonts (*Plus Jakarta Sans*, *Fira Code*), FontAwesome 6.
- **CI/CD & Hosting:** GitHub Pages via automated Git workflow.
